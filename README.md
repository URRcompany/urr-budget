# ReelBudget

하나의 영상제작 프로젝트 예산을 관리하는 웹 앱입니다.

## 기능

- 프로젝트명 · 클라이언트 · 촬영일 · 총 예산 설정
- 카테고리별 배정 예산 vs 집행액 비교 (출연, 스태프, 장비, 로케이션 등)
- 지출 추가 / 수정 / 삭제
- 카테고리 필터
- 브라우저 `localStorage`에 자동 저장

## 실행

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

샘플 프로젝트 「브랜드 필름 — 새벽의 레시피」가 기본으로 로드됩니다. 데이터는 브라우저에만 저장됩니다.
