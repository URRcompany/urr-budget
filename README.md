# ReelBudget

영상제작 프로젝트 예산을 다중으로 관리하는 웹 앱입니다.

## 기능

- **다중 프로젝트**: 생성 · 삭제 · 목록에서 합산 순수익 확인
- **세부 비용 카테고리**: 인건비, 출연료, 식비, 교통비, 장비대여비, 로케이션비, 미술·소품, 후반작업, 보험·허가, 기타 (+ 커스텀 추가)
- **지출 CRUD** 및 카테고리 필터
- **최종 순수익**: 계약·매출 − 총 집행 비용 (마진율 포함)
- 브라우저 `localStorage` 자동 저장

## 실행

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

샘플 프로젝트 2개가 기본으로 로드됩니다. 이전에 쓰던 단일 프로젝트 데이터는 자동으로 마이그레이션됩니다.
